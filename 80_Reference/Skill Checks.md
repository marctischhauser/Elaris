## Faustregel

**Etwas bemerken?** → Perception  
**Etwas verstehen/untersuchen?** → Investigation  
**Etwas wissen?** → Arcana / History / Nature / Religion  
**Kraft?** → Athletics  
**Geschicklichkeit?** → Acrobatics  
**Schleichen?** → Stealth  
**Menschen beeinflussen?** → Persuasion / Deception / Intimidation  
**Wildnis?** → Survival

---
## Wahrnehmung & Untersuchung

|Skill|Verwendung|
|---|---|
|**Perception**|Etwas bemerken, hören, riechen, versteckte Gefahren entdecken|
|**Investigation**|Hinweise analysieren, Fallenmechanismen verstehen, Rätsel lösen|
|**Insight**|Lügen erkennen, Absichten einschätzen|

### Beispiele

- Versteckte Tür finden → Perception
- Morsche Brücke erkennen → Investigation
- Nervösen Händler durchschauen → Insight

---

## Wissen

|Skill|Verwendung|
|---|---|
|**Arcana**|Magie, Zauber, magische Kreaturen|
|**History**|Geschichte, Legenden, Personen|
|**Nature**|Pflanzen, Tiere, Wetter|
|**Religion**|Götter, Kulte, Untote|

### Beispiele

- Magisches Artefakt identifizieren → Arcana
- Alte Ruinen erkennen → History
- Giftige Pflanze bestimmen → Nature    

---

## Körperliche Aktionen

|Skill|Verwendung|
|---|---|
|**Athletics**|Klettern, Springen, Schwimmen, Kraftakte|
|**Acrobatics**|Balancieren, Ausweichen, Gleichgewicht halten|
|**Stealth**|Schleichen, Verstecken|

### Beispiele

- Klippe erklimmen → Athletics
- Über eine einstürzende Brücke laufen → Acrobatics
- An Wachen vorbeischleichen → Stealth

---

## Soziale Interaktionen

|Skill|Verwendung|
|---|---|
|**Persuasion**|Überzeugen, Verhandeln|
|**Deception**|Lügen, Täuschen|
|**Intimidation**|Einschüchtern, Drohen|
|**Performance**|Auftreten, Musik, Schauspiel|

### Beispiele

- Händler um Rabatt bitten → Persuasion
- Sich als Wache ausgeben → Deception
- Banditen bedrohen → Intimidation

---

## Überleben & Umgebung

| Skill               | Verwendung                                     |
| ------------------- | ---------------------------------------------- |
| **Survival**        | Spuren verfolgen, Nahrung finden, Orientierung |
| **Animal Handling** | Tiere beruhigen oder kontrollieren             |
| **Medicine**        | Verletzungen beurteilen, Stabilisieren         |

### Beispiele

- Wolfsspuren verfolgen → Survival
- Pferd beruhigen → Animal Handling
- Bewusstlosen stabilisieren → Medicine
